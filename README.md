# AbrScript — Сценарии

Модуль для Топоматик Robur: сценарии на Python и графы из узлов для повторяющихся действий в открытом проекте. Сценарий — обычный текстовый файл: его можно написать, сохранить и запустить, не собирая плагин.

```python
# Перенести отрезки длиннее 10 м на отдельный слой
drawing.add_layer("Длинные", 1)
for e in drawing.entities("line"):
    if e.length > 10:
        e.layer = "Длинные"
```

## Возможности

- Своя вкладка ленты «Сценарии»: диспетчер, примеры, создание, быстрые сценарии, помощь
- Диспетчер сценариев: разделы и категории, поиск, вид списком, плитками или таблицей, карточка с запуском и выводом; открывается окном, можно закрепить вкладкой проекта
- 37 встроенных примеров (текст и графы): «Посмотреть» без записи в библиотеку или «Взять себе»; среди них «Ведомость демонтажа», объёмы по слоям, площади штриховок, нумерация объектов, отметки по полилинии
- Графы — визуальные сценарии из узлов, без программирования (файлы `.abrg`)
- Быстрые сценарии: до 8 кнопок на ленте со своей подписью и значком
- Редактор с подсветкой, проверка синтаксиса до запуска, ошибки с номером строки
- Пробный запуск: сценарий выполняется, изменения отменяются — видно, что получится
- Всё, что сценарий изменил за запуск, отменяется одной «Отменой»; при ошибке изменения отменяются сами; Esc останавливает сценарий
- Чертёж: поиск объектов по типу и слою, свойства (слой, цвет, текст, длина, площадь), перемещение, поворот, удаление, создание примитивов, слои, выделение, таблицы на чертёж
- Чтение проекта, поверхностей и дорог; таблицы результатов с экспортом в CSV и Excel
- Импорт LISP: задание для внешнего ИИ по файлу `.lsp` и встроенный «Промпт для ИИ»
- Чужой сценарий помечается как не доверенный: перед запуском модуль показывает, что нашёл в его тексте

## Установка

Через менеджер модулей **ABR | Библиотека модулей** (требуется модуль [AbrModules](https://github.com/Y-Abramov/AbrModules)):

1. Открыть **ABR → Модули → Управление модулями**
2. Найти **Сценарии** в каталоге
3. Нажать **Установить** и перезапустить Robur

Пакет `.tpm` — в разделе [Releases](https://github.com/Y-Abramov/AbrScript/releases).
